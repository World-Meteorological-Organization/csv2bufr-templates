csv2bufr-templates
==================

Example mapping templates for converting CSV observation data to BUFR with
`csv2bufr <https://csv2bufr.readthedocs.io>`_.

.. note::

   The templates in this repository are example templates provided to assist
   with encoding observational data to BUFR format using csv2bufr. They are
   **not** official WMO data formats or standards. Users are responsible for
   ensuring that any encoded data meets the requirements of the intended data
   exchange or submission.
